# pagina_web_para_hyperventas
Desarrollé el sitio web de un negocio real que vendía solo por Mercado Libre. Diseñé una página rápida, accesible y orientada a generar confianza, con catálogo, contacto directo por WhatsApp y un panel de administración para que el dueño actualice precios y stock sin tocar código. Stack: JavaScript, Netlify, Supabase
